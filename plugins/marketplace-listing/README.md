# marketplace-listing

Creates optimized listings for Facebook Marketplace, Kijiji, and Craigslist.

## What it does

Given an item you want to sell, this skill:

1. Researches the current retail price from Canadian retailers
2. Pulls accurate specs and compatibility information
3. Writes a clean, buyer-friendly listing with retail price references and source links
4. Suggests a pricing range based on condition and retail value

## Installation

```
/plugin install EricMarcantonio/skills/plugins/marketplace-listing
```

## Trigger

The skill activates whenever you want to sell something — cars, tires, rims, electronics, furniture, tools, or any physical item. Just describe the item casually and it kicks in automatically.

Examples:
- "Help me sell my winter tires"
- "I want to post my old monitor on Facebook Marketplace"
- "Create a listing for my set of rims"
